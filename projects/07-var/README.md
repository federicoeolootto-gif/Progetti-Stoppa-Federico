# Macroeconomic VAR · Impulse-Response Analysis

**Question:** How do identified macroeconomic shocks propagate through a system of economic variables over time?

University project extending a US shortage-shock VAR with Euro Area variables, using eight time series, a VAR(2), recursive Cholesky identification and impulse-response functions over a 20-quarter horizon.

**Methods:** stationarity / lag considerations, VAR estimation, identification assumptions and IRF interpretation. The raw code, input time series and exact model replication remain pending audit; this page documents the analytical scope, **not** a reproduced empirical finding.
