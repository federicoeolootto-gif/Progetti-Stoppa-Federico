# Evidence map — what is original and what is public

A recruiter should be able to distinguish **the actual project** from **the material that can be shared**.

| Case study | Nature / contribution | Evidence currently in this repository | Important boundary |
|---|---|---|---|
| Support Operations | Business Intelligence internship with QlikView and KPI-oriented work | Fabricated ticket dataset, PostgreSQL schema and queries, independently implemented Python report | The dataset and queries are NOT employer material |
| Education & Climate | Collaborative university empirical project using econometrics and ML | A separate synthetic train/test and cross-validation example | Does not reproduce the original study or causal estimates |
| FantaGiungla | Personal Airtable-connected auction-analytics application | Independent, fictional event-processor example and technical explanation | No real participant data, live API integration or model validation published |
| Nova | Personal Electron/Node.js AI-integrated desktop application | Independent mocked-provider fallback demo and unit tests | Not the original app, live API client or evidence of Windows production reliability |
| PaperLens | Configuration / experimentation / extensions of upstream open-source system | Architecture and attribution only | Original code, secrets, backups and upstream-derived code withheld |
| Historical roads | Individual master's thesis; further academic work in progress | Research question and methods overview | No prepublication/coauthor dataset or unpublished scripts |
| VAR | University macroeconometric work | Technical summary | Raw data and reproducible notebook not included |
| Pirelli | Group finance/valuation case study | Methods and interpretation summary | Proprietary financial exports excluded |
| Geospatial | Inspired by a recruitment data task | Independent, runnable and fictional Python aggregation script | Not the original selection exercise |
| Bonn / Mean field / Optimization / Other | Academic and individual/group experiences | Descriptive overviews | Unverified or non-distributable materials withheld |

All examples are intended as **inspectable technical evidence**, not proof of commercial impact or predictive performance. More original reproducible code can be released after checking authorship, licenses and secrets.
