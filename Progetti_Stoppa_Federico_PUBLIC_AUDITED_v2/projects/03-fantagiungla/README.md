# FantaGiungla — Auction Analytics & Decision Support

**Individual application, under active development:** Airtable data model for player records, performance history, ranking, auction constraints and event ingestion. The private system also uses external auction events, budget scenarios and real-time dashboards. **Predictive machine learning is a current development activity, not a finished evaluated model.** The end-to-end application has not been publicly revalidated.

## Public technical illustration

[`public_event_demo.py`](public_event_demo.py) is a new, independent implementation showing **input validation, event de-duplication, bid sequencing, budget constraints and aggregate state updates** on wholly fictional participants. It is not the private application's source, real auction dataset or real ML model.

```bash
python public_event_demo.py
```

**Withheld:** Airtable base IDs/invites, access tokens, webhook destinations, auction room URLs, cookies, real participants' names, real bids and third-party FantaLab source/materials. The original application code is not published while permission and security reviews remain outstanding.
